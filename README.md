# GoogleFormZIPtoUTF8csv
Extract the Google Forms ZIP file and convert it to UTF-8 encoding.


# 🏫 Googleフォーム CSV文字化け一括解消ツール

GIGAスクール構想により「Google for Education」が導入され、学校現場ではGoogleフォームを使ったアンケートや小テスト、日々の健康観察などが簡単に実施できるようになりました。

しかし、その集計結果をダウンロードして **Microsoft Excelで開くと「文字化け」してしまう** という問題が頻発しています。さらに、ダウンロードされたファイルは「ZIP形式」で圧縮されていることが多く、先生方は**「ZIPファイルの解凍」と「文字コードの変換」という2つの煩雑な作業**を強いられていました。

本ツールは、この煩わしい作業を**ドラッグ＆ドロップの1ステップで一気に解決**する、教職員のための業務効率化アプリです。

---

## 🌟 本質的な特徴（選ばれる理由）

### 1. ZIP解凍 ＋ 文字化け解消を「全自動化」
Googleフォームからダウンロードした「ZIPファイル」をそのまま画面にドロップするだけで、自動的に中身のCSVファイルを取り出し、Excelで正しく読める形式（BOM付きUTF-8）に変換してダウンロードします。

### 2. インストール不要の「シングルファイルHTML」
本アプリは `index.html` という1つのファイルだけで完結しています。教育委員会の厳しいセキュリティ制限によって新しいソフトがインストールできない校務用PCでも、EdgeやChromeなどのWebブラウザで開くだけですぐに使用できます。

### 3. データ漏洩リスクゼロの「ローカル処理」
児童生徒の氏名や成績といった機密データを扱う教育現場を想定し、**データは一切インターネット上のサーバーへ送信されません。** すべての処理は、先生方のパソコンのメモリ上（ブラウザ内）だけで安全に完結します。

---

## 🛠 根本的な原因（なぜ文字化けするのか？）

* **事実1:** Googleフォームから出力されるCSVファイルは、世界標準の「UTF-8」という文字コードで作られています。
* **事実2:** 日本のWindows環境のExcelは、CSVファイルを開く際、古い国内標準である「Shift-JIS」という文字コードであると勝手に思い込んで読み込みます。
* **結論:** この「文字コードのすれ違い」が文字化けの原因です。本ツールは、CSVファイルの先頭に「これはUTF-8ですよ」とExcelに教える目印（BOM：Byte Order Mark）を自動で付与することで、この問題を根本から解決します。

## 📖 使い方（初心者向けの3ステップ）

### ステップ1：ツールの起動
1. 本ツールのファイル（例: `CsvBomConverter.html`）をダブルクリックします。
2. 使い慣れたWebブラウザ（Microsoft Edge, Google Chromeなど）で専用画面が開きます。

### ステップ2：ファイルの投入
1. Googleフォームの管理画面から、アンケート結果をダウンロードします（ZIPファイルが保存されます）。
2. 保存されたZIPファイルを、本ツールの「ここにCSVまたはZIPファイルをドラッグ＆ドロップ」という枠の中に重ねてドロップします。

### ステップ3：完了・Excelで開く
1. 一瞬で処理が完了し、文字化けが解消されたCSVファイルが自動的にダウンロードフォルダに保存されます。
2. 保存されたCSVファイルをダブルクリックしてExcelで開いてください。綺麗な日本語で表示されていれば成功です。

## ⚠️ 初心者が見落としやすい点と対策（トラブルシューティング）

**Q. ZIPの中に複数のCSVがあった場合、1つしかダウンロードされません。**
**A. ブラウザの「複数ダウンロード制限」が作動しています。**
> 1回の操作で複数のファイルをダウンロードしようとすると、ブラウザが安全のために処理をブロックすることがあります。
> 画面右上のアドレスバー付近に「ポップアップがブロックされました」または「複数ファイルのダウンロード」に関する警告アイコンが出たら、クリックして**「常に許可する」**を選択してください。次回からは全ファイルが自動でダウンロードされます。

**Q. 変換元のファイル名が変わってしまいますか？**
**A. いいえ、変わりません。**
> 業務システムへの取り込みや、他の先生との共有時に困らないよう、元のファイル名（例: `1年A組_健康観察.csv`）をそのまま維持してダウンロードする仕様になっています。

**Q. インターネットに繋がっていないPCでも使えますか？**
**A. 初回のみインターネット接続が必要です。**
> ZIPファイルを解凍するための設計図（外部ライブラリ）をインターネット上から安全に読み込んでいます。そのため、完全にオフラインのPCではZIPドロップ時の処理が動きません。インターネットに繋がる校務用PC等でご利用ください。
